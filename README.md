# Evil Number Guessing Game 😈

About

Evil Number Guessing Game is a troll-style number guessing game built using Python.

The computer chooses a number between 1 and 50, and the player tries to guess it. But there's a twist: whenever the player guesses the computer's chosen number correctly, the computer changes its number and declares the player wrong! 😂

Features

- Random number selection between 1 and 50
- Unlimited guessing attempts
- Troll-style game logic
- Displays the player's guess and the computer's updated number
- A frustrating but fun gameplay experience 😈

Technologies Used

- Python

Files

- "evil_number_guessing_game.py" — Python source code
- "evil_number_guessing_game.exe" — Executable version for Windows

How to Run

Using Python

1. Download the Python source file.
2. Install Python if it isn't already installed.
3. Open a terminal in the file's directory.
4. Run the following command:

python evil_number_guessing_game.py

Using the Windows Executable

1. Download "evil_number_guessing_game.exe".
2. Run it on a Windows computer.

Purpose

This project was created to practise Python fundamentals, random number generation, loops, conditional statements, and game logic.

Note

The computer changing its number when the player guesses correctly is an intentional feature of this troll game—not a bug! 😂😈
